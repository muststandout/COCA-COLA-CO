# COCA-COLA-CO
Excel Power Query, DATA Visualization(Dashboard)
______________________________________________________________________________________________________________________________________________________________________________________________________________________________
Project Overview

An Excel-based financial analysis of The Coca-Cola Company from 2009–2018, using financial statement data to identify business trends, investigate changes in financial performance, and understand cash flow.
The project demonstrates how Excel can be used to turn financial data into business insights and answers to real-world analytical questions.

Tools used

- Microsoft Excel
- XLOOKUP
- Pivot Tables
- Data Transformation
- Dashboard & Data Visualization

Business Questions

This analysis was designed to answer questions such as:

- How did Coca-Cola's revenue and profitability change over time?
- Which years had the strongest and weakest financial performance?
- Why did net income change significantly in certain years?
- How did Coca-Cola's assets and debt change over the 10-year period?
- Which years experienced negative changes in cash?
- What were the main factors behind those negative cash-flow years?
- How did Coca-Cola use the cash generated from its operations?
- Are there any unusual trends or financial outliers worth investigating?
______________________________________________________________________________________________________________________________________________________________________________________________________________________________
Key Insights

- Revenue reached its highest point around 2012, followed by a significant decline in later years
- Coca-Cola maintained positive operating cash flow throughout the period
- Several years experienced a negative overall change in cash, despite strong operating cash generation
- 2017 stood out as a significant net-income outlier, making it an important year for further investigation
- Total assets increased substantially over the 10-year period
